**DOCUMENT USAGE GUIDELINES:**

*   **Comprehensive List:** This document contains the definitive list of standardized keywords and recurring game mechanics.
*   **Stability of Definitions:** The names and core definitions of these keywords are stable. Do not alter without explicit design approval.
*   **Adding New Keywords:** New keywords should only be added if a fundamentally new, recurring mechanic is introduced that cannot be adequately represented by existing terms or combinations.
*   **GDD Context:** Refer to the main Game Design Document (GDD) for how these keywords interact within the broader game systems. This glossary provides definitions, the GDD provides application and interaction context.

---

*   **Armor:** A temporary Health point pool that takes damage before a creature's Health. Recoil damage also hits Armor first. Armor can be removed by specific effects. *(GDD Context: III.F.3)*
*   **Banish:** Permanently removes a card (from hand, board, discard pile, or deck) from the game. Banished cards are outside all game zones and irretrievable. *(GDD Context: II.E.5)*
*   **Cleanse:** An action or effect that actively removes one or more status effects from a target. Specific cleanse effects will define which types of statuses they can remove. *(GDD Context: III.C.4)*
*   **Concealed Action:** An action that is not visible to the opponent in any pre-resolution preview and appears as '???' in the opponent's Turn History upon resolution. Generated by the `Concealed` status or an `Undercover` ability. *(GDD Context: I - Fog of War; Status Effects Compendium for `Concealed` status)*
*   **Conversion:** An effect that allows a player to gain permanent control of an opponent's creature. *(GDD Context: IV.D)*
*   **Creature-Targeting:** An effect or action that targets a specific creature. If the targeted creature moves to a different slot before the action resolves, the action will still affect that same creature in its new location (homing). If the creature dies before resolution, the effect redirects to the slot it last occupied. *(GDD Context: III.F.5)*
*   **Deployment Time:** A state applied to creatures upon entering the battlefield, lasting X turns, during which they typically cannot act or trigger passive abilities. Its duration can be manipulated. *(GDD Context: II.C; Status Effects Compendium for full definition as a state/status)*
*   **Interference:** A category of pre-set effects that trigger during the Pre-Resolution Interference Phase to modify an opponent's queued action. Types include `Nullify (Interference)`, `Reorder (Interference)`, and `Redirect (Interference)`. *(GDD Context: III.D.4)*
*   **Nullify (Interference):** An `Interference` effect that causes a specific opponent's pending action to be marked as "Nullified," resolving with no game effect.
*   **Reorder (Interference):** An `Interference` effect that alters a pending action's `Priority (Action)` or other properties influencing its resolution order.
*   **Redirect (Interference):** An `Interference` effect that changes the target of a specific opponent's pending action.
*   **Priority (Action):** A value assigned to an action that determines its resolution order within the Action Queue, superseding creature Speed. Higher `Priority (Action)` actions resolve before lower `Priority (Action)` actions. *(GDD Context: II.F)*
*   **Recruitment:** An effect that allows a player to gain temporary control of an opponent's creature. *(GDD Context: IV.D)*
*   **Requisite:** A condition or set of conditions that must be met (e.g., sacrificing a creature, discarding cards) before a card can be played or an ability activated. *(GDD Context: II.E.8)*
*   **Revive:** An ability or Spell that returns a creature card from a player's Discard Pile to an empty battlefield slot. *(GDD Context: III.E.1)*
*   **Scheduled Draw:** The primary mechanism for drawing cards, occurring at the Start of a player's Turn. The number of cards drawn is based on a base amount plus modifiers. *(GDD Context: II.E.1)*
*   **Slot-Targeting:** An effect or action that targets a specific battlefield slot. If a creature in that slot moves, the effect impacts whatever is in the slot at resolution. *(GDD Context: III.F.5)*
*   **Strategic Disclosure:** A beneficial effect that triggers for the player who successfully reveals an opponent's concealed information (via an Intelligence action or applying the `Revealed` status). *(GDD Context: IV.A.1)*
*   **Trap (Counter-Intelligence):** A detrimental effect that triggers against an opponent when they reveal specific concealed information or interact with a trapped action/slot. *(GDD Context: IV.A)*
*   **Undercover (Ability):** A passive creature ability causing all actions queued by that creature to be `Concealed Actions`. *(GDD Context: VI.B for example; see `Concealed Action` in this glossary)*
