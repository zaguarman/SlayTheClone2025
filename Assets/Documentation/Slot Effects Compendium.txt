Surveillance Post
    Visibility: Hidden
    Trigger Event(s): OnEnterSlot(movingCreature, enteredSlot, method) (Slot effect logic checks: if enteredSlot is this slot and movingCreature is an enemy to the controller of this Slot Effect).

    Parameters: None.
    Duration of Slot Effect: 1 Trigger (consumed immediately after its effect is queued, as per GDD 3.11 Instant Effects).
    Cleansable: Yes

Binding Chains
    Visibility: Visible
    Trigger Event(s): OnBeforeLeaveSlot(leavingCreature, slot, method) (Slot effect logic checks: if slot is this slot and the creature is starting a Movement Action of its own).
    Effect: Before the creature leaves, it gains Anchored, so its move is cancelled. The Binding Chains is then consumed. It resolves immediately, like every environment action (GDD 3.7 Resolution Order).
    Notes: Only the creature's own movement is stopped. A friendly Push or Swap still moves it out, and being moved removes Anchored.
    Parameters: None.
    Duration of Slot Effect: 1 Trigger (consumed immediately after its effect is queued, as per GDD 3.11 Instant Effects).
    Cleansable: Yes

Slippery Floor
    Visibility: Hidden
    Trigger Event(s): OnEnterSlot(movingCreature, enteredSlot, method) (Slot effect logic checks: if enteredSlot is this slot).
    Effect: The movingCreature slides one extra slot in the direction it was moving, if that slot is empty and it can be moved. If it can't (the board's edge, an occupied slot, Heavy or multi-slot, or it entered without a direction, e.g., summoned), it takes 2 damage instead. The Slippery Floor is then revealed and consumed.
    Notes: Being slid isn't the creature's own movement. The extra slot it lands on counts as entered (OnEnterSlot).
    Parameters: Damage if not pushed: 2 (set by applying card).
    Duration of Slot Effect: 1 Trigger (consumed immediately after its effect is queued, as per GDD 3.11 Instant Effects).
    Cleansable: Yes.

Unstable Terrain
    Visibility: Visible
    Trigger Event(s): OnTurnEnd (Slot effect logic checks if its slot is occupied).
    Effect: If this is the 2nd consecutive Day the same creature ends its Day on this slot, that creature is moved to a random available adjacent friendly slot (if multiple, chosen randomly). If no such slot is available, nothing happens. The "consecutive Day" counter resets if a different creature occupies the slot, the slot becomes empty, or the creature is successfully moved by this effect or any other means.
    Parameters: None.
    Duration of Slot Effect: Persistent until replaced.
    Cleansable: Yes

Magnetic Pulse
    Visibility: Visible
    Trigger Event(s): OnTurnStart (Slot effect logic checks if its slot is occupied by a creature controlled by the player who applied Magnetic Pulse).
    Effect: At Dawn (Start of the Day), if their creature is on this slot, the enemy creature nearest to the slot opposite this one (ties broken randomly) is pulled one slot toward that opposite slot, if the slot it would move into is empty and it can be moved. Nothing happens if an enemy creature is already in the opposite slot.
    Notes: Being pulled isn't the creature's own movement, so Anchored doesn't stop it; Heavy and multi-slot creatures can't be pulled. It lines enemies up in front of your creature, setting up slot-targeted attacks.
    Parameters: None.
    Duration of Slot Effect: Persistent until replaced.
    Cleansable: Yes
